## 🔍 백엔드 로그 빠른 검색

### 가장 많이 사용할 검색어들:

#### 1. 우리 백엔드 로그만 보기
```
server:backend
```

#### 2. 애플리케이션 로그만 (시스템 로그 제외)
```
server:backend AND logtype:application
```

#### 3. 에러 로그 찾기
```
server:backend AND (message:*ERROR* OR message:*Exception*)
```

#### 4. API 요청 로그
```
server:backend AND message:*/api/group-buys*
```
