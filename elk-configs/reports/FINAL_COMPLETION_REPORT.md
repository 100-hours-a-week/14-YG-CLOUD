### 🎯 **추천 사용 시나리오**

#### 🐛 버그 디버깅 시
1. Discover에서 `server.keyword:"backend" AND message:*ERROR*` 검색
2. 시간 범위를 문제 발생 시점으로 설정
3. 에러 메시지와 스택트레이스 확인
4. 연관된 로그들을 시간순으로 추적

#### 📊 성능 분석 시  
1. Dashboard에서 API 성능 차트 확인
2. 응답시간이 급증한 시점 식별
3. 해당 시간대 에러 로그 연관성 분석
4. 서버 리소스 사용률과 비교

#### 🚨 장애 대응 시
1. Error Analysis Dashboard에서 전체 현황 파악
2. 서버별 에러 분포로 장애 범위 확인  
3. 최근 심각한 에러로 근본 원인 추적
4. 시간대별 트렌드로 장애 진행 상황 모니터링
