### CPU vs 메모리 요구사항
```bash
AI 서버 주요 작업:
1. LangGraph 추론 (RECURSION_LIMIT=15)
2. Vertex AI API 호출 (네트워크 I/O 중심)
3. 모델 결과 처리 및 캐싱

특성:
- 대부분 API 호출 → CPU 사용률 낮음
- 메모리는 모델 결과 캐싱용 → 16GB 필요
- I/O 대기 시간 많음 → 단일 vCPU로도 충분할 가능성
```
