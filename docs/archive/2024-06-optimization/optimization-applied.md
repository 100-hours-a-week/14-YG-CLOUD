## 🎯 성능 영향 분석

### ✅ Jump Box (`e2-small`)
- **CPU**: 0.5 vCPU (버스트 가능) → WireGuard용 충분
- **메모리**: 2GB → SSH 연결 관리 충분
- **용도**: 단순 VPN 게이트웨이로 완벽

### ✅ Backend/AI 디스크 감소
- **Backend**: 30GB → Spring Boot + 로그용 적정
- **AI**: 40GB → AI 모델 + 캐시용 적정
- **성능**: 디스크 용량만 줄였으므로 성능 영향 없음
